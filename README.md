# 🗄️ SQL Retail & Sales Data Analysis Project

## 🚀 Overview

This project was completed during my **Data Technician Bootcamp** and demonstrates the use of **SQL** to query, analyse, and extract insights from relational databases.

Working with retail and sales datasets, I developed practical experience in retrieving, filtering, sorting, joining, and summarising data to answer real-world business questions. The project focused on transforming raw data into actionable insights that support business decision-making.

---

## 🛠️ Skills Demonstrate

### 📋 Data Retrieval
- `SELECT` statements to retrieve data from tables
- Selecting specific columns for reporting
- Using `DISTINCT` to identify unique values
- Limiting returned results for focused analysis 

### 🔍 Data Filtering
- `WHERE` clauses to filter records
- Using comparison operators (`=`, `>`, `<`, `>=`, `<=`)
- Applying `IN`, `BETWEEN`, and `LIKE`
- Combining conditions with `AND` and `OR` operators 

### 📊 Data Sorting & Organisation
- `ORDER BY` for ascending and descending sorting
- Organising customer, sales, and product information
- Creating structured business reports from database queries 

### 📈 Aggregation & Analysis
- `COUNT()` to calculate totals
- `SUM()` to calculate sales volumes
- `GROUP BY` to summarise data by category
- Producing category and product-level performance reports 

### 🔗 SQL JOINs
- `INNER JOIN`
- `LEFT JOIN`
- `RIGHT JOIN`
- `FULL JOIN`
- Combining data across multiple tables

Used JOINs to connect:
- Customers and Orders
- Products and Categories
- Products and Suppliers
- Order Details and Products

This allowed the creation of comprehensive business reports that combined information from multiple related tables.

### 📦 Product & Inventory Reporting
- Linked products to suppliers

### 📋 Order Analysis
- Analysed customer orders and transaction history

- Combined order, customer, and employee information
- Investigated sales volumes and product demand 

### 🌍 Database Exploration
- Queried relational databases using real-world scenarios
- Worked with multiple related tables
- Retrieved and analysed global demographic data
- Applied SQL techniques to explore large datasets efficiently
